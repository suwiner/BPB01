02 / COMMON QUESTIONS

你可能还想知道。

我们把重要的信息，说清楚。

安装版与便携版的区别是什么？+

安装版提供常规安装流程；便携版解压后运行。两者均面向 Windows 10/11 64 位。

为什么下载按钮显示不可用？+

官网会核对公开 GitHub Release 中的文件名、大小以及可用的校验摘要。若没有匹配的正式附件，按钮不会提供无效链接。

如何确认下载文件完整？+

使用 Windows 系统工具计算文件的 SHA256，再与本页面的校验清单比较。

是否已经提供 macOS 版本？+

当前下载中心只列出 Windows 10/11 64 位版本。其他系统版本如正式发布，会另行提供。

Android 手机版在哪里下载？+

已新增 Android 7.0.0 独立 APK 下载入口，支持 Android 9 及以上。它与 Windows 8.32.0 是不同版本，安装前请自行核对兼容性及 SHA256 校验值。
