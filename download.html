从下载安装到版本升级，简单说明。

墨鱼浏览器支持什么系统？ +

目前提供 Windows 10、Windows 11 的 64 位桌面版本；暂未发布官方 macOS 安装包。

安装版和便携版有什么区别？ +

安装版使用标准安装程序；便携版解压即可运行，适合自主管理文件位置的用户。

如何校验下载文件？ +

在 PowerShell 中执行页面给出的 Get-FileHash 命令，将生成值与本页 SHA256 逐位比较。

为什么下载按钮显示“暂未上架”？ +

这表示对应的公开发布附件尚未找到或未通过校验。为了避免失效或错误下载，网站在文件公开上架且匹配后才开放按钮。

更新版本前要做什么？ +

先关闭墨鱼浏览器，建议备份重要收藏、日常记录和账号保险库，妥善保管主密码，再运行新版安装程序。
