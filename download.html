关于下载、安装、升级和使用的常见问题。

墨鱼浏览器支持哪些系统？

目前提供 Windows 10、Windows 11 的 64 位桌面版本。其他系统暂未提供安装包。

安装版与便携版有什么区别？

安装版通过安装向导完成部署；便携版解压后运行。两者均基于 8.32.0 版本，推荐普通用户选择安装版。

升级前需要注意什么？

请先退出正在运行的墨鱼浏览器，再运行新版安装程序。重要收藏、报告、笔记及账号保险库等数据建议自行备份，主密码请妥善保存。

系统出现未知发布者或安全提示怎么办？

当前版本尚未使用商业代码签名。若系统出现安全警告，请先核对下载来源、文件 SHA256 及系统安全提示，不应忽略或强行绕过未知风险。

可以导入其他浏览器的收藏吗？

可以手动导入 HTML / JSON 书签文件，并保留原有文件夹层级。出于数据控制考虑，墨鱼不会在启动时自动扫描或导入其他浏览器的收藏。
