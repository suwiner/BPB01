安装版和便携版有什么区别？ +

安装版提供常规安装体验；便携版可解压运行。两者均面向 Windows 10/11 的 64 位系统。

下载按钮为什么暂时不可用？ +

官网仅在确认正式 GitHub Release 中存在对应的安装文件且大小匹配后启用下载，避免跳转到不存在的文件。

怎样校验安装文件的完整性？ +

下载完成后使用系统工具计算 SHA256，和此页面提供的校验清单逐项对比。

是否有 macOS 和移动版？ +

目前这里发布的是 Windows 10/11 的 64 位版本；其他系统版本如正式发布，会另行公告。
