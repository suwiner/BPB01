# 墨鱼浏览器 Android V2.2.0 并存修复版

## 安装冲突处理

旧安装器提示“更新包与已安装应用的签名不一致”，这是 Android 的应用签名校验，无法绕过。
此版本更换为独立的 `applicationId=com.moyu.browser.mobile`，旧版本 `com.moyu.mobile` 保留；新版本**单独安装**，不覆盖、不读取旧应用私有数据。
为便于用户识别，新应用名称为“墨鱼浏览器·独立版”。如果之前安装了早期 `com.moyu.browser.v5`，也可以与之并存。

## 交付与签名

代码使用原生 Android + WebView，保留 V2.1 的黑白默认主题、等比例 LOGO、工具箱、待办提醒、日报周报、书签导入导出、网页查找和 PDF 功能。
GitHub Actions 只生成 **DEBUG 构建中间产物**，不会发布调试签名作为正式下载附件。
发行 APK 需在可信离线环境中，使用项目拥有者私下备份的稳定签名密钥（SHA-256 证书指纹 E9:26:BE:F3:50:36:F4:30:61:5A:F5:BC:F5:1A:A7:94:51:F8:DC:7F:57:05:D2:5B:A6:DA:1D:5C:1C:42:5B:72）重新签名并校验。
**请不要将私钥、密码、keystore 上传到公开 GitHub 仓库或发行附件。** 后续版本请复用该安全备份签名密钥。

## 功能与约束

- 默认黑白、可选深色和柔和蓝白；原比例矢量墨鱼图标。
- Google/百度搜索、可编辑首页快捷网址、多标签页、网页翻译入口、电脑模式、网页查找。
- 书签 HTML/JSON 导入及导出 JSON、下载、PDF 保存、分享、基础追踪域名拦截。
- 独立工具箱：便签、待办提醒、可编辑日报周报、周报汇总、计算器、AI 官方动态、分类网址导航、天气/农历入口。
- **尚不支持** PC 插件 CRX、完整广告过滤、PC 云同步。系统提醒受电池优化与通知权限影响。
- 新旧包名不同，本地书签、密码及工作记录不会自动从旧版转入；保留旧版以便备份。
- 目前未完成真机全面回归测试，不宣称已彻底修复所有机型兼容问题。

构建命令：`gradle -p moyu-android :app:assembleDebug`（需要 JDK17 / Android SDK35）。
